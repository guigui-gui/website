Build GUIs in Go. Just Go.

Guigui is an immediate-mode-inspired GUI framework powered by Ebitengine. Build and extend widgets with Go and Ebitengine APIs, without HTML, CSS, JavaScript, or a C compiler.

Target Windows, macOS, Linux, and browsers from a shared codebase, with straightforward cross-compilation, Hi-DPI rendering, built-in internationalization, and optimized draw calls.

Features

Compilable without C compilers

Compile Guigui applications with only the Go toolchain. Cross-compile for other platforms without setting up target-specific C compilers, simplifying multi-platform releases.

Multiplatform

Build for Windows, macOS, Linux, and web browsers from one Go codebase, preserving the interface's structure and behavior across platforms.

No HTML, CSS, or JavaScript

Define layouts, widgets, event handling, and application logic entirely in Go, without maintaining a separate web frontend stack.

Hi-DPI support

Keep text, controls, and graphics sharp and readable across displays with different pixel densities through consistent interface scaling.

Built-in internationalization

Adapt interface text and content for multiple languages with built-in internationalization, without creating a localization system from scratch.

Efficient rendering

Guigui reduces rendering overhead by optimizing draw calls and avoiding unnecessary work, keeping complex interfaces responsive as they grow.

Powered by Ebitengine

Built on Ebitengine, Guigui lets custom widgets use its drawing, input, and other APIs directly. You can also embed another Ebitengine app as a widget alongside standard Guigui controls.

Immediate-mode-inspired

Its immediate-mode-inspired API keeps interface code direct, making state changes and behavior easy to express in ordinary Go.
