Build GUIs in Go. Just Go.

Guigui is an immediate-mode-inspired GUI framework powered by Ebitengine. Build extensible widgets in Go for Windows, macOS, Linux, and browsers, without HTML, CSS, JavaScript, or a C compiler.

Image

go run github.com/guigui-gui/guigui/example/gallery@latest

Features

Compilable without C compilers

The Go toolchain is all you need to compile Guigui applications. They can be cross-compiled for other platforms without setting up target-specific C compilers, simplifying multiplatform releases.

Multiplatform

A single Go codebase targets Windows, macOS, Linux, and web browsers while preserving the interface’s structure and behavior across platforms.

No HTML, CSS, or JavaScript

Layouts, widgets, event handling, and application logic are all written in Go, with no separate web frontend stack to maintain.

Hi-DPI support

Consistent interface scaling keeps text, controls, and graphics sharp and readable across displays with different pixel densities.

Built-in internationalization

Guigui supports multilingual text input through IMEs and automatically selects appropriate fonts based on the user’s locale.

Efficient rendering

Guigui reduces rendering overhead by optimizing draw calls and avoiding unnecessary work, keeping complex interfaces responsive as they grow.

Powered by Ebitengine

Built on Ebitengine, Guigui gives custom widgets direct access to its drawing, input, and other APIs. Guigui can also embed another Ebitengine app as a widget alongside standard controls.

Immediate-mode-inspired

Guigui’s immediate-mode-inspired API keeps interface code direct, making state changes and behavior easy to express in ordinary Go.

AI friendly

A dedicated skill file helps AI coding agents develop Guigui applications. Ebitengine’s virtual machine support also lets agents run and test them programmatically.
