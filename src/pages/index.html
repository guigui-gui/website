Build GUIs in Go. Just Go.

Guigui is an immediate-mode-inspired GUI framework powered by Ebitengine. Build and extend widgets with Go and Ebitengine APIs, without HTML, CSS, JavaScript, or a C compiler.

Target Windows, macOS, Linux, and browsers from a shared codebase, with straightforward cross-compilation, Hi-DPI rendering, built-in internationalization, and optimized draw calls.

Features

Compilable without C compilers

Compile Guigui applications with the Go toolchain without installing or configuring a C compiler. You can also cross-compile for other platforms without preparing a target-specific C cross-compiler, simplifying multi-platform release builds.

Multiplatform

Build graphical applications for Windows, macOS, Linux, and web browsers from a shared Go codebase. Keep the same interface structure and behavior while targeting each supported platform.

No HTML, CSS, or JavaScript

Define the interface and its behavior in Go without adding a separate web frontend stack. Layouts, widgets, event handling, and application logic all stay together in the same language.

Hi-DPI support

Keep text, controls, and graphics clear on modern displays with different pixel densities. Interfaces scale consistently, so applications remain sharp and readable across a wide range of screens.

Built-in internationalization

Create interfaces for multiple languages with internationalization support included. Adapt visible text and interface content for different audiences without building a separate localization system from scratch.

Efficient rendering

Guigui optimizes draw calls to reduce rendering overhead and improve application performance. By avoiding unnecessary rendering work, complex interfaces can remain responsive as their content and controls grow.

Powered by Ebitengine

Guigui is built on Ebitengine, so custom widgets can use Ebitengine APIs directly for drawing, input, and other behavior. You can even embed other Ebitengine-powered content as widgets alongside standard Guigui controls.

Immediate-mode-inspired

Keep interface code direct and easy to follow with an API inspired by immediate-mode GUIs. The approach makes state changes and interface behavior easier to express in ordinary Go code.
